# Quy tắc sửa mã nguồn (Code Modification Rule)

- **BẮT BUỘC:** Không được tự ý sửa đổi mã nguồn (source code) hay ghi đè file trong dự án khi chưa hỏi ý kiến và nhận được sự đồng ý / xác nhận từ người dùng.
- Khi phát hiện lỗi hoặc đề xuất cải tiến:
  1. Phân tích nguyên nhân và giải thích rõ ràng cho người dùng.
  2. Đưa ra giải pháp và hiển thị đoạn code đề xuất.
  3. Hỏi ý kiến người dùng trước khi thực hiện chỉnh sửa file.
