======================================================================
 CadCoreFramework - PLUGIN AUTOCAD .NET (KHUNG MẪU + LỆNH MINH HỌA)
======================================================================

1. CÀI ĐẶT:
- Giải nén toàn bộ file ZIP ra một thư mục (KHÔNG chạy trực tiếp trong file ZIP).
- Nhấp đúp chuột vào file "Install.bat" để cài đặt tự động vào AutoCAD.
- Mở AutoCAD (tương thích AutoCAD 2021 trở lên). Plugin được Autoloader tự nạp.

2. CÁC LỆNH SỬ DỤNG TRONG AUTOCAD:
- CORE_INFO          : Kiểm tra plugin đã khởi tạo và sẵn sàng.
- CORE_TEST_ALL      : Tự kiểm tra hạ tầng (tạo layer, vẽ hình chữ nhật, chữ, XData).
- SAMPLE_GRID        : Vẽ lưới ô đánh nhãn A1, A2, ... (khuôn mẫu Golden Sample).
- SHOW_PALETTE       : Mở Palette Grid Marker gắn cạnh màn hình CAD.
- CADCORE_LAYER_MANAGER : Mở Palette quản lý Layer.
- CORE_DEBUG         : Mở Debug Inspector (lịch sử lệnh, service, sự kiện).
- DEMO_HELP          : Danh sách toàn bộ lệnh minh họa DEMO_* (nếu bản build có kèm demo).

3. GỠ BỎ:
- Tắt AutoCAD, rồi nhấp đúp chuột vào file "Uninstall.bat".
